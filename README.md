# AI-Ready Project Starter Template (Python 3.11+)

Профессиональный инженерный шаблон («рыба») для быстрого и надежного старта любых новых задач разработки и автоматизации с использованием ИИ.

---

## 📁 Структура проекта

```text
Plan/
├── .gitignore               # Исключение кэшей, виртуальных сред и секретов
├── .env.example             # Шаблон переменных окружения
├── requirements.txt         # Базовые проверенные зависимости
├── AGENTS.md                # Системные стандарты и инструкции для ИИ-ассистентов
├── TASK_STATE.md            # Чек-лист и трекер выполнения текущей задачи
├── README.md                # Данное руководство
│
├── src/                     # Исходный код приложения
│   ├── __init__.py
│   ├── config.py            # Pydantic Settings (чтение .env)
│   ├── models.py            # Pydantic v2 схемы данных и валидация
│   ├── services.py          # Чистая бизнес-логика и обработка
│   └── main.py              # Точка входа (пайплайн)
│
└── tests/                   # Автоматические тесты
    └── test_services.py     # Тесты бизнес-логики (pytest)
```

## 🚀 Как использовать этот шаблон для НОВОЙ задачи

Когда поступает новая задача, выполните 4 простых шага:

### Шаг 1. Скопируйте папку шаблона в новую директорию
```bash
# Пример: создаем папку для новой задачи
cp -r "D:/!!Ai/Antigravity/Tools/Plan" "D:/!!Ai/Antigravity/MyNewTask"
```

### Шаг 2. Разверните окружение и зависимости
```bash
cd "D:/!!Ai/Antigravity/MyNewTask"
python -m venv .venv
# Активация на Windows:
.venv\Scripts\activate
# Установка базового стека:
pip install -r requirements.txt
# Создание рабочего файла переменных окружения:
cp .env.example .env
```

### Шаг 3. Заполните `TASK_STATE.md`
Перед написанием первой строчки кода сформулируйте задачу в `TASK_STATE.md`:
1. Что подается на вход.
2. Что должно получиться на выходе.
3. Разбейте путь на 3–4 этапа.

### Шаг 4. Работайте с ИИ по этапам
1. **Модели (`src/models.py`)**: Опишите структуру входных и выходных данных.
2. **Тест (`tests/test_services.py`)**: Попросите ИИ написать тест на 1 тестовый пример.
3. **Функция (`src/services.py`)**: Попросите ИИ реализовать функцию до успешного прогона `pytest`.
4. **Сборка (`src/main.py`)**: Объедините шаги в точке входа.

---

## 🧪 Запуск тестов и приложения

```bash
# Запуск тестов:
pytest -v

# Запуск приложения:
python -m src.main
```
