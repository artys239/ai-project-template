# AI-Ready Project Starter Template (Python 3.11+)

Профессиональный инженерный шаблон («рыба») для быстрого и надежного старта любых новых задач разработки и автоматизации с использованием ИИ.

---

## 📁 Структура проекта

```text
Plan/
├── setup.bat                # Скрипт автоматического развертывания в 1 клик на Windows
├── .gitignore               # Исключение кэшей, виртуальных сред и секретов
├── .env.example             # Шаблон переменных окружения
├── requirements.txt         # Базовые проверенные зависимости
├── AGENTS.md                # Системные стандарты и инструкции для ИИ-ассистентов
├── TASK_STATE.md            # Чек-лист и трекер выполнения текущей задачи
├── README.md                # Данное руководство
│
├── src/                     # Исходный код приложения
│   ├── __init__.py
│   ├── config.py            # Pydantic Settings (чтение .env с fallback)
│   ├── models.py            # Pydantic v2 схемы данных и валидация
│   ├── services.py          # Чистая бизнес-логика и обработка
│   └── main.py              # Точка входа (пайплайн с логированием)
│
└── tests/                   # Автоматические тесты
    └── test_services.py     # Unit-тесты (совместимы с pytest и unittest)
```

## 💻 Пошаговый план: Работа на НОВОМ компьютере

Когда вы садитесь за новый или «чистый» рабочий компьютер:

### Шаг 0. Базовые программы (один раз на новом ПК)
1. Установите **Python 3.11+** с официального сайта [python.org](https://www.python.org/).  
   ⚠️ **Критически важно:** при установке обязательно поставьте галочку **"Add python.exe to PATH"**.
2. Установите **Git** с сайта [git-scm.com](https://git-scm.com/).
3. Установите редактор кода (**VS Code / Cursor / Antigravity**).

---

### Шаг 1. Получение шаблона под новую задачу

Выберите один из двух удобных вариантов:

* **Вариант А (через кнопку GitHub — рекомендуется):**
  1. Откройте репозиторий шаблона: [github.com/artys239/ai-project-template](https://github.com/artys239/ai-project-template).
  2. Нажмите зеленую кнопку **«Use this template»** $\rightarrow$ **«Create a new repository»**.
  3. Укажите название вашей новой задачи (например, `hvac-price-parser`) и нажмите **Create repository**.
  4. Склонируйте свой новый репозиторий на ПК:
     ```bash
     git clone https://github.com/artys239/hvac-price-parser.git
     cd hvac-price-parser
     ```

* **Вариант Б (копированием папки локально):**
  Просто скопируйте папку шаблона в новое место:
  ```powershell
  Copy-Item -Recurse "D:\!!Ai\Antigravity\Tools\Plan" "C:\Projects\MyNewTask"
  cd "C:\Projects\MyNewTask"
  ```

---

### Шаг 2. Развертывание окружения

#### Самый быстрый способ (1 клик):
Дважды кликните по файлу **`setup.bat`**.  
Скрипт автоматически:
1. Проверит наличие Python.
2. Создаст изолированное окружение `.venv`.
3. Установит все библиотеки из `requirements.txt`.
4. Создаст рабочий файл `.env` из шаблона.
5. Запустит тесты для подтверждения готовности.

#### Ручной способ (через терминал PowerShell):
```powershell
# 1. Создаем виртуальное окружение:
python -m venv .venv

# 2. Активируем его:
.venv\Scripts\activate

# 3. Устанавливаем зависимости:
pip install -r requirements.txt

# 4. Копируем файл конфигурации:
copy .env.example .env

# 5. Проверяем работоспособность тестами:
python -m unittest discover tests -v
```

---

### Шаг 3. Заполнение `TASK_STATE.md` перед разработкой
Откройте `TASK_STATE.md` в редакторе и опишите цель:
1. Что подается на вход (файл, текст, таблица, API).
2. Какой результат ожидается на выходе.
3. Разбейте путь на 3–4 шага.

---

### Шаг 4. Взаимодействие с ИИ
Скопируйте в чат с моделью готовый запрос:
> *«Привет! Мы делаем новую задачу. Ознакомься со стандартами в `AGENTS.md` и целью в `TASK_STATE.md`. Сначала спроектируй Pydantic-модели в `src/models.py`. Код функций пока не пиши, начни с согласования контрактов данных»*.

## 🧪 Полезные команды

```powershell
# Активация окружения (если терминал открыт заново):
.venv\Scripts\activate

# Запуск тестов:
pytest -v
# или стандартным модулем:
python -m unittest discover tests -v

# Запуск основного скрипта:
python -m src.main
```
